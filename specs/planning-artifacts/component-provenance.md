# Component Provenance Registry

Central source-provenance registry for the toolkit, mandated by
`architecture.md#provenance--governance-patterns` and `epics.md` (FR: provenance
tracked centrally with `crm | website | new` source labels and rationale).

For each delivered or enhanced component, record:

- **source** — `crm` (canonical behavior), `website` (visual/variant gap-fill), or `new`
- **rationale** — why that source is canonical for this component
- **alignment notes** — behavior/visual decisions and any documented deviations

New entries are appended by the delivering story. Existing entries are updated
(not rewritten) when a later story enhances a component.

Ownership split: the consumer owns `open`, the **component owns focus** — focus always enters the menu on open (pointer and keyboard alike; `first`, or `last` only for ArrowUp), returns to the trigger synchronously on Escape and on activation, and is rescued when the menu is closed underneath it, so it is never dropped to `<body>` (SC 2.4.3). `aria-activedescendant` and roving `tabindex="0"` are forbidden — the menu contributes zero tab stops; empty `items` renders no menu at all (the `UiItemsList` empty-renders-nothing rule). `disabled` uses the repo `aria-disabled` boundary (focusable, native `disabled` never set) and **dominates** `open`: closed presentation, every open path a no-op, no self-emitted `onOpenChange(false)`. Focus ring: **single-layer** `inset 0 0 0 2px darkPrimary` on trigger and rows alike (this card paints its own white fill, so 3.2's second white layer buys nothing) plus a `forced-colors` outline branch. The photo is **decorative** (`alt=""`), diverging from `UiTaskCard`'s informative avatar by the contract's own ruling — the name beside it is already the trigger's accessible name. **Deviations:** `value`/`onChange` N/A (`onOpenChange`/`onSelect` are the analogues); `error`/`size`/`variant` N/A (a single master; rest/hover/open/disabled are states, not variants); `onOpenChange` carries a boolean unlike 3.1's bare `onToggle()` (five close paths race a payload-free toggle); typeahead out of scope, on record.
